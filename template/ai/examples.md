# Examples

Examples help agents understand usage patterns.

Examples are not answer evidence unless a canon entry or evidence card explicitly references them as evidence.

## Example Question

```text
What does this page officially claim?
```

## Expected Reading Behavior

```text
1. Read page.json for the manifest.
2. Select a route from routes.json.
3. Read canon.md.
4. Read relevant evidence cards.
5. Answer only from canon and evidence.
```
